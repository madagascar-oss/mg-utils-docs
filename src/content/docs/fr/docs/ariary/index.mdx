## Formatage

Les montants sont des nombres, entiers ou décimaux, sans limite haute dans les règles. Les milliers sont groupés par une espace insécable (ou un point), et les décimales suivent une virgule. La virgule n’est jamais un séparateur de milliers.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { formatAriary } from '@mdgascar/ariary';

    formatAriary(1500); // 'Ar 1 500'
    formatAriary(1500.5); // 'Ar 1 500,5'
    formatAriary(2026000, { grouping: 'dot' }); // 'Ar 2.026.000'
    formatAriary(1234567.89, { grouping: 'dot' }); // 'Ar 1.234.567,89'
    formatAriary(1500, { symbolPosition: 'after' }); // '1 500 Ar'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Ariary\Ariary;
    use Mdgascar\MdgUtils\Ariary\Grouping;
    use Mdgascar\MdgUtils\Ariary\SymbolPosition;

    Ariary::fromInt(1500)->format(); // 'Ar 1 500'
    Ariary::fromFloat(1500.5)->format(); // 'Ar 1 500,5'
    Ariary::fromInt(2026000)->format(Grouping::Dot); // 'Ar 2.026.000'
    Ariary::fromFloat(1234567.89)->format(Grouping::Dot); // 'Ar 1.234.567,89'
    Ariary::fromInt(1500)->format(position: SymbolPosition::After); // '1 500 Ar'
    ```
  </TabItem>
</Tabs>

<Aside>Les espaces du résultat sont insécables (U+00A0) : un montant n’est jamais coupé sur deux lignes.</Aside>

## Lire les montants saisis

`Ar 1 500`, `1.500 Ar`, `MGA 1500` et `1 500` se lisent tous 1500, et `1 500,50 Ar` se lit 1500.5. Les signes sont refusés, comme le point utilisé comme virgule décimale.

<TryItBox module="ariary" input="1 500,50 Ar" examples={['1 500,50 Ar', '1.234.567,89', 'Ar 0,25', '1,500', '1,5,0', '-1 500', 'Ar 1 500 Ar']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { parseAriary, safeParseAriary, tryParseAriary } from '@mdgascar/ariary';

    parseAriary('1.500 Ar'); // 1500
    parseAriary('MGA 1500'); // 1500
    parseAriary('1 500,50 Ar'); // 1500.5
    parseAriary('1,500'); // 1.5 (the comma is the decimal separator)

    tryParseAriary('1.5'); // undefined: a dot is not a decimal point by default
    const result = safeParseAriary('1.5');
    if (!result.success) result.error.code; // 'INVALID_FORMAT'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    Ariary::parse('1.500 Ar')->amount; // 1500
    Ariary::parse('MGA 1500')->amount; // 1500
    Ariary::parse('1 500,50 Ar')->amount; // 1500.5
    Ariary::parse('1,500')->amount; // 1.5 (the comma is the decimal separator)

    Ariary::tryParse('1.5'); // null: a dot is not a decimal point by default
    Ariary::safeParse('1.5')->error?->errorCode; // ErrorCode::InvalidFormat
    ```
  </TabItem>
</Tabs>

<Aside type="caution">Par défaut `1,500` se lit **1,5** : à Madagascar, la virgule sépare les décimales. Un texte écrit à l’anglaise, où `1,500` veut dire mille cinq cents, serait lu 1000 fois trop petit. Si vos saisies peuvent avoir cette forme, indiquez-le avec les options ci-dessous. Ce choix par défaut est à revoir, voir les règles.</Aside>

## Autres conventions

Chaque option vaut par défaut l’usage malgache. Pour un texte écrit selon une autre convention, passez `grouping` et `decimal` : la bibliothèque ne devine jamais. Les deux doivent être des caractères différents.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    formatAriary(1500.5, { grouping: 'comma', decimal: 'dot' }); // 'Ar 1,500.5'
    parseAriary('1,500.50', { grouping: 'comma', decimal: 'dot' }); // 1500.5
    parseAriary('1,500', { grouping: 'comma', decimal: 'dot' }); // 1500
    formatAriary(1500, { grouping: 'comma' }); // throws MdgError INVALID_TYPE: same as the decimal comma
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Ariary\DecimalSeparator;

    Ariary::fromFloat(1500.5)->format(Grouping::Comma, decimal: DecimalSeparator::Dot); // 'Ar 1,500.5'
    Ariary::parse('1,500.50', Grouping::Comma, DecimalSeparator::Dot)->amount; // 1500.5
    Ariary::parse('1,500', Grouping::Comma, DecimalSeparator::Dot)->amount; // 1500
    Ariary::fromInt(1500)->format(Grouping::Comma); // throws MdgUtilsException, ErrorCode::InvalidType
    ```
  </TabItem>
</Tabs>

## Montants en lettres

Pour les reçus et les chèques : le montant en lettres malgaches suivi de `ariary`. Les décimales suivent `faingo`.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { spellAriary } from '@mdgascar/ariary';

    spellAriary(1500); // 'dimanjato sy arivo ariary'
    spellAriary(25000); // 'dimy arivo sy roa alina ariary'
    spellAriary(1500.5); // 'dimanjato sy arivo faingo dimy ariary'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    Ariary::fromInt(1500)->spell(); // 'dimanjato sy arivo ariary'
    Ariary::fromInt(25000)->spell(); // 'dimy arivo sy roa alina ariary'
    Ariary::fromFloat(1500.5)->spell(); // 'dimanjato sy arivo faingo dimy ariary'
    ```
  </TabItem>
</Tabs>

## Anciens francs malgaches (FMG)

5 FMG = 1 Ar. La conversion est exacte en décimal : des francs non divisibles par 5 donnent des ariary décimaux, jamais un artefact d’arrondi.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { ariaryToFmg, fmgToAriary, formatFmg } from '@mdgascar/ariary';

    fmgToAriary(7500); // 1500
    fmgToAriary(7501); // 1500.2
    ariaryToFmg(1500); // 7500
    ariaryToFmg(0.07); // 0.35 (exact, never 0.35000000000000003)
    formatFmg(7500); // 'Fmg 7 500'
    formatFmg(7500.5); // 'Fmg 7 500,5'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    Ariary::fromFmg(7500)->amount; // 1500
    Ariary::fromFmg(7501)->amount; // 1500.2
    Ariary::fromInt(1500)->toFmg(); // 7500
    Ariary::fromFloat(0.07)->toFmg(); // 0.35 (exact)
    Ariary::formatFmg(7500); // 'Fmg 7 500'
    Ariary::formatFmg(7500.5); // 'Fmg 7 500,5'
    ```
  </TabItem>
</Tabs>

## Erreurs

| Entrée | Code d’erreur |
| --- | --- |
| Pas un nombre fini, options invalides, ou même caractère pour les milliers et les décimales | `INVALID_TYPE` |
| Texte avec signe, point comme virgule décimale (par défaut) ou autre devise | `INVALID_FORMAT` |
| Inférieur à 0, ou au-delà du plus grand nombre exact du langage | `OUT_OF_RANGE` |
