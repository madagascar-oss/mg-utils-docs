## Installer un module avec npm

Chaque module est un paquet distinct : `@mdgascar/words`, `@mdgascar/phone`, `@mdgascar/ariary` et `@mdgascar/date`. Ils fonctionnent avec Node.js 22.18+, Deno, Bun et tous les navigateurs modernes.

<Steps>

1. ### Installer le paquet

   Ajoutez le module voulu. Cet exemple utilise les numéros de téléphone.

   ```sh title="Terminal"
   npm install @mdgascar/phone
   ```

2. ### Importer une fonction

   Chaque module exporte de simples fonctions. Lisez un numéro écrit de n’importe quelle façon courante et formatez-le.

   ```ts title="signup.ts"
   import { formatPhone, parsePhone } from '@mdgascar/phone';

   const phone = parsePhone('034 12 345 67');
   phone.operator; // 'yas'

   formatPhone('0341234567', 'international'); // '+261 34 12 345 67'
   ```

3. ### Gérer les saisies invalides

   Les fonctions `parse…` lèvent une `MdgError`. Utilisez `safeParse…` pour obtenir le code d’erreur sans exception, ou `tryParse…` pour obtenir `undefined`.

   ```ts title="signup.ts"
   import { safeParsePhone, tryParsePhone } from '@mdgascar/phone';

   const result = safeParsePhone('031 12 345 67');
   if (!result.success) result.error.code; // 'UNKNOWN_OPERATOR'

   tryParsePhone('not a number'); // undefined
   ```

4. ### Vérifier le résultat

   Les codes d’erreur sont les mêmes dans tous les langages : un formulaire affiche le même message, que la vérification ait eu lieu dans le navigateur ou sur un serveur PHP.

   ```ts title="signup.ts"
   import { MdgError, parsePhone } from '@mdgascar/phone';

   try {
     parsePhone(userInput);
   } catch (error) {
     if (error instanceof MdgError) console.log(error.code); // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>

## TypeScript

Chaque option, format et code d’erreur est un type : l’éditeur les complète, et une faute de frappe ne compile pas.

```ts title="signup.ts"
import { safeParsePhone, type PhoneNumber, type PhoneNumberFormat } from '@mdgascar/phone';
import { spell, type SpellOptions } from '@mdgascar/words';
import type { ErrorCode } from '@mdgascar/phone';

function phoneOrError(input: string): PhoneNumber | ErrorCode {
  const result = safeParsePhone(input);
  return result.success ? result.data : result.error.code; // narrowed by `success`
}

const format: PhoneNumberFormat = 'international'; // 'e164' | 'international' | 'national'
const options: SpellOptions = { system: 'traditional' }; // 'standard' | 'traditional'
spell(30_000_000, options); // 'telo safatsiroa'
```
