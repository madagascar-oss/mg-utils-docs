## Fametrahana môdily amin’ny npm

Fonosana tokana ny môdily tsirairay: `@madagascar-oss/words`, `@madagascar-oss/phone`, `@madagascar-oss/ariary` ary `@madagascar-oss/date`. Mandeha amin’ny Node.js 22.18+, Deno, Bun ary ny mpitety tranonkala maoderina rehetra izy ireo.

<Steps>

1. ### Apetraho ny fonosana

   Ampio ny môdily ilainao. Laharan-telefaonina no ampiasain’ity ohatra ity.

   ```sh title="Terminal"
   npm install @madagascar-oss/phone
   ```

2. ### Ampidiro ny asa iray

   Asa tsotra no avoakan’ny môdily tsirairay. Vakio ny laharana na ahoana na ahoana fomba nanoratana azy ary soraty indray.

   ```ts title="signup.ts"
   import { formatPhoneNumber, parsePhoneNumber } from '@madagascar-oss/phone';

   const phone = parsePhoneNumber('034 12 345 67');
   phone.operator; // 'telma'

   formatPhoneNumber('0341234567', 'international'); // '+261 34 12 345 67'
   ```

3. ### Tantano ny fampidirana diso

   Manipy `MgError` ny asa `parse…`. Ampiasao ny `safeParse…` mba hahazoana ny kaody hadisoana tsy misy fanipazana, na `tryParse…` mba hahazoana `undefined`.

   ```ts title="signup.ts"
   import { safeParsePhoneNumber, tryParsePhoneNumber } from '@madagascar-oss/phone';

   const result = safeParsePhoneNumber('035 12 345 67');
   if (!result.success) result.error.code; // 'UNKNOWN_OPERATOR'

   tryParsePhoneNumber('not a number'); // undefined
   ```

4. ### Hamarino ny valiny

   Mitovy amin’ny fiteny rehetra ny kaody hadisoana, ka afaka mampiseho hafatra mitovy ny taratasy fenoina, na tao amin’ny mpitety na tao amin’ny mpizara PHP no nanamarinana.

   ```ts title="signup.ts"
   import { MgError, parsePhoneNumber } from '@madagascar-oss/phone';

   try {
     parsePhoneNumber(userInput);
   } catch (error) {
     if (error instanceof MgError) console.log(error.code); // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>
