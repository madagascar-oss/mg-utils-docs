## Utilisation de base

Le malgache lit les nombres de la plus petite unité à la plus grande. La partie la plus petite se relie à 10 par `ambin'ny`, à 20–90 et à 100 exactement par `amby`, à 200–900 et aux groupes plus grands par `sy`.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { numberToWords } from '@mdgascar/words';

    numberToWords(0); // 'aotra'
    numberToWords(11); // "iraika ambin'ny folo"
    numberToWords(21); // 'iraika amby roapolo'
    numberToWords(101); // 'iraika amby zato'
    numberToWords(205); // 'dimy sy roanjato'
    numberToWords(348); // 'valo amby efapolo sy telonjato'
    numberToWords(1960); // 'enimpolo sy sivinjato sy arivo'
    numberToWords(2026); // 'enina amby roapolo sy roa arivo'
    numberToWords(10000); // 'iray alina'
    numberToWords(280000); // 'valo alina sy roa hetsy'
    numberToWords(1000000); // 'iray tapitrisa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Words\NumberWords;

    NumberWords::fromInt(0); // 'aotra'
    NumberWords::fromInt(11); // "iraika ambin'ny folo"
    NumberWords::fromInt(21); // 'iraika amby roapolo'
    NumberWords::fromInt(101); // 'iraika amby zato'
    NumberWords::fromInt(205); // 'dimy sy roanjato'
    NumberWords::fromInt(348); // 'valo amby efapolo sy telonjato'
    NumberWords::fromInt(1960); // 'enimpolo sy sivinjato sy arivo'
    NumberWords::fromInt(2026); // 'enina amby roapolo sy roa arivo'
    NumberWords::fromInt(10000); // 'iray alina'
    NumberWords::fromInt(280000); // 'valo alina sy roa hetsy'
    NumberWords::fromInt(1000000); // 'iray tapitrisa'
    ```
  </TabItem>
</Tabs>

## Grands nombres

Les règles n’ont pas de limite haute : `lavitrisa` (10⁹), le plus grand mot de groupe, prend un multiplicateur de toute taille, écrit avec les mêmes règles. Chaque langage s’arrête seulement là où ses nombres cessent d’être exacts : `Number.MAX_SAFE_INTEGER` en JavaScript, `PHP_INT_MAX` en PHP.

## Décimales

La partie entière vient d’abord, puis `faingo` (la virgule), puis les chiffres après la virgule lus comme un nombre entier. Chaque zéro juste après la virgule se dit `aotra`.

<TryItBox module="words" input="3.14" examples={['3.14', '18.3', '0.5', '1.05', '0.008', '12.75', '1234.5678']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    numberToWords(3.14); // "telo faingo efatra ambin'ny folo"
    numberToWords(18.3); // "valo ambin'ny folo faingo telo"
    numberToWords(0.5); // 'aotra faingo dimy'
    numberToWords(1.05); // 'iray faingo aotra dimy'
    numberToWords(0.008); // 'aotra faingo aotra aotra valo'
    numberToWords(12.75); // "roa ambin'ny folo faingo dimy amby fitopolo"
    numberToWords(1.0); // 'iray' (a whole number has no faingo)
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::fromFloat(3.14); // "telo faingo efatra ambin'ny folo"
    NumberWords::fromFloat(18.3); // "valo ambin'ny folo faingo telo"
    NumberWords::fromFloat(0.5); // 'aotra faingo dimy'
    NumberWords::fromFloat(1.05); // 'iray faingo aotra dimy'
    NumberWords::fromFloat(0.008); // 'aotra faingo aotra aotra valo'
    NumberWords::fromFloat(12.75); // "roa ambin'ny folo faingo dimy amby fitopolo"
    NumberWords::fromFloat(1.0); // 'iray' (a whole number has no faingo)
    ```
  </TabItem>
</Tabs>

<Aside>Les décimales sont celles de la valeur numérique. `1.50` est le nombre `1.5`, et `0.1 + 0.2` vaut `0.30000000000000004` en virgule flottante : il se lit donc ainsi.</Aside>

## Des nombres uniquement

L’entrée est une valeur numérique, jamais du texte : ni espaces, ni séparateurs, ni chaînes. `'1 500'` donne `INVALID_TYPE`. Pour lire des montants saisis, utilisez le module ariary.

## Erreurs

| Entrée | Code d’erreur |
| --- | --- |
| Pas un nombre fini (`'21'`, `NaN`, `Infinity`) | `INVALID_TYPE` |
| Inférieur à 0 | `OUT_OF_RANGE` |
| Au-delà du plus grand nombre exact du langage | `OUT_OF_RANGE` |

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    numberToWords(-1); // throws MdgError, error.code === 'OUT_OF_RANGE'
    numberToWords('1 500' as unknown as number); // throws MdgError, 'INVALID_TYPE'
    numberToWords(Number.MAX_SAFE_INTEGER + 1); // throws MdgError, 'OUT_OF_RANGE'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::fromInt(-1); // throws MdgUtilsException, ->errorCode === ErrorCode::OutOfRange
    NumberWords::fromFloat(NAN); // throws MdgUtilsException, ErrorCode::InvalidType
    ```
  </TabItem>
</Tabs>

## Pas encore pris en charge

Les nombres négatifs, et les anciens noms de 10⁷ et au-delà (`safatsiroa`, `tsitamboisa`…), attendent une source ou l’avis d’un expert de la langue malgache. Voir [En attente d’une source ou d’un expert](/mdg-utils-docs/fr/docs/words/rules/#waiting-for-a-source-or-an-expert).
