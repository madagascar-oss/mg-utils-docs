## Fampiasana fototra

Ekena avokoa ny elanelana, ny tsipika, ny teboka, ny fonon-teny, ny `+261`, ny `00261` ary ny `0` eo am-piandohana.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { parsePhoneNumber } from '@mdgascar/phone';

    parsePhoneNumber('034 12 345 67');
    // { e164: '+261341234567', nationalNumber: '341234567', operator: 'telma' }

    parsePhoneNumber('+261 32 12 345 67').operator; // 'orange'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Phone\PhoneNumber;

    $phone = PhoneNumber::parse('034 12 345 67');
    $phone->e164;           // '+261341234567'
    $phone->nationalNumber; // '341234567'
    $phone->operator;       // Operator::Telma

    PhoneNumber::parse('+261 32 12 345 67')->operator; // Operator::Orange
    ```
  </TabItem>
</Tabs>

## Fanoratana

Endrika telo: `e164` ho an’ny fitahirizana sy ny API, `international` ho an’ny any ivelany, `national` ho an’ny eto Madagasikara.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { formatPhoneNumber } from '@mdgascar/phone';

    formatPhoneNumber('034 12 345 67', 'e164'); // '+261341234567'
    formatPhoneNumber('034 12 345 67', 'international'); // '+261 34 12 345 67'
    formatPhoneNumber('+261341234567', 'national'); // '034 12 345 67'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Phone\PhoneNumber;
    use Mdgascar\MdgUtils\Phone\PhoneNumberFormat;

    $phone = PhoneNumber::parse('034 12 345 67');
    $phone->format(PhoneNumberFormat::E164);          // '+261341234567'
    $phone->format(PhoneNumberFormat::International); // '+261 34 12 345 67'
    $phone->format(PhoneNumberFormat::National);      // '034 12 345 67'
    ```
  </TabItem>
</Tabs>

## Fanamarinana ny fampidiran’ny mpampiasa

Tsy manipy hadisoana mihitsy ny `isValid`. Ny `safeParse` dia milaza ny antony nandavana ny laharana, ny `tryParse` dia manome ny laharana na tsy misy.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { isValidPhoneNumber, safeParsePhoneNumber, tryParsePhoneNumber } from '@mdgascar/phone';

    isValidPhoneNumber('035 12 345 67'); // false

    const result = safeParsePhoneNumber('035 12 345 67');
    if (!result.success) result.error.code; // 'UNKNOWN_OPERATOR'

    tryParsePhoneNumber('035 12 345 67'); // undefined
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    PhoneNumber::isValid('035 12 345 67'); // false

    $result = PhoneNumber::safeParse('035 12 345 67');
    $result->error?->errorCode; // ErrorCode::UnknownOperator

    PhoneNumber::tryParse('035 12 345 67'); // null
    ```
  </TabItem>
</Tabs>

## Hadisoana

| Fampidirana                                              | Kaody hadisoana         |
| -------------------------------------------------- | ------------------ |
| Tsy soratra                                       | `INVALID_TYPE`     |
| Tsy laharana finday malagasy (halava diso, litera) | `INVALID_FORMAT` |
| Tovona tsy omena mpandraharaha (`035`)  | `UNKNOWN_OPERATOR` |
