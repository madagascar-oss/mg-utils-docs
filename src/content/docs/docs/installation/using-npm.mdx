## Installing a module with npm

Each module is its own package: `@mdgascar/words`, `@mdgascar/phone`, `@mdgascar/ariary` and `@mdgascar/date`. They run in Node.js 22.18+, Deno, Bun and every modern browser.

<Steps>

1. ### Install the package

   Add the module you need. This example uses phone numbers.

   ```sh title="Terminal"
   npm install @mdgascar/phone
   ```

2. ### Import a function

   Every module exports plain functions. Read a number written in any common way and format it.

   ```ts title="signup.ts"
   import { formatPhoneNumber, parsePhoneNumber } from '@mdgascar/phone';

   const phone = parsePhoneNumber('034 12 345 67');
   phone.operator; // 'yas'

   formatPhoneNumber('0341234567', 'international'); // '+261 34 12 345 67'
   ```

3. ### Handle bad input

   `parse…` functions throw an `MdgError`. Use `safeParse…` to get the error code without throwing, or `tryParse…` to get `undefined`.

   ```ts title="signup.ts"
   import { safeParsePhoneNumber, tryParsePhoneNumber } from '@mdgascar/phone';

   const result = safeParsePhoneNumber('031 12 345 67');
   if (!result.success) result.error.code; // 'UNKNOWN_OPERATOR'

   tryParsePhoneNumber('not a number'); // undefined
   ```

4. ### Check the result

   Error codes are the same in every language, so a form can show the same message whether the check ran in the browser or on a PHP server.

   ```ts title="signup.ts"
   import { MdgError, parsePhoneNumber } from '@mdgascar/phone';

   try {
     parsePhoneNumber(userInput);
   } catch (error) {
     if (error instanceof MdgError) console.log(error.code); // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>

<Aside type="caution" title="Before the first npm release">
  The packages are published to npm with the first release. Until then, install them from
  [mdg-utils-js](https://github.com/mdgascar/mdg-utils-js) or try them in the
  [playground](/mdg-utils-docs/play/).
</Aside>
