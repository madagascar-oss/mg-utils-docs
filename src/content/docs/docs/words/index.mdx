## Basic usage

Malagasy reads numbers from the smallest unit up. The smaller part joins 10 with `ambin'ny`, 20–90 and exactly 100 with `amby`, and 200–900 and every larger group with `sy`.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { numberToWords } from '@madagascar-oss/words';

    numberToWords(0); // 'aotra'
    numberToWords(21); // 'iraika amby roapolo'
    numberToWords(205); // 'dimy sy roanjato'
    numberToWords(1960); // 'enimpolo sy sivinjato sy arivo'
    numberToWords(10_000); // 'iray alina'
    numberToWords(1_000_000); // 'iray tapitrisa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Madagascar\MgUtils\Words\NumberWords;

    NumberWords::fromInt(0); // 'aotra'
    NumberWords::fromInt(21); // 'iraika amby roapolo'
    NumberWords::fromInt(205); // 'dimy sy roanjato'
    NumberWords::fromInt(1960); // 'enimpolo sy sivinjato sy arivo'
    NumberWords::fromInt(10_000); // 'iray alina'
    NumberWords::fromInt(1_000_000); // 'iray tapitrisa'
    ```
  </TabItem>
</Tabs>

## Errors

| Input                               | Error code     |
| ----------------------------------- | -------------- |
| Not a whole number (`1.5`, `'21'`)  | `INVALID_TYPE` |
| Below 0 or above 999 999 999 999    | `OUT_OF_RANGE` |

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    numberToWords(-1); // throws MgError, error.code === 'OUT_OF_RANGE'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::fromInt(-1); // throws MgUtilsException, ->errorCode === ErrorCode::OutOfRange
    ```
  </TabItem>
</Tabs>
