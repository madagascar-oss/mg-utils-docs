## How it works

The [spec repository](https://github.com/madagascar-oss/mg-utils-spec) holds, for each module, the rules in plain words, the data with an official source and the date it was checked, and the **test vectors**: inputs with the exact output or error code every port must produce.

```text
mg-utils-spec           data, rules, Public API tables, test vectors
  ├─ mg-utils-js        includes the spec, generates its tables, runs every vector
  └─ mg-utils-php       includes the spec, generates its tables, runs every vector
```

<CardGrid>
  <Card title="Tests are the contract" icon="approve-check">

  </Card>
  <Card title="Same error codes" icon="warning">

  </Card>
  <Card title="Three ways to parse" icon="list-format">
    `parse` throws, `safeParse` returns the value or the error code, `tryParse` returns the value or nothing.
  </Card>
  <Card title="Sources for every value" icon="open-book">
    No source, no merge: data comes from laws, regulators or recognised dictionaries.
  </Card>
</CardGrid>
