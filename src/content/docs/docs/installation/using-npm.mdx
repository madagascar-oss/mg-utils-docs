## Installing a module with npm

Each module is its own package: `@madagascar-oss/words`, `@madagascar-oss/phone`, `@madagascar-oss/ariary` and `@madagascar-oss/date`. They run in Node.js 22.18+, Deno, Bun and every modern browser.

<Steps>

1. ### Install the package

   Add the module you need. This example uses phone numbers.

   ```sh title="Terminal"
   npm install @madagascar-oss/phone
   ```

2. ### Import a function

   Every module exports plain functions. Read a number written in any common way and format it.

   ```ts title="signup.ts"
   import { formatPhoneNumber, parsePhoneNumber } from '@madagascar-oss/phone';

   const phone = parsePhoneNumber('034 12 345 67');
   phone.operator; // 'telma'

   formatPhoneNumber('0341234567', 'international'); // '+261 34 12 345 67'
   ```

3. ### Handle bad input

   `parse…` functions throw an `MgError`. Use `safeParse…` to get the error code without throwing, or `tryParse…` to get `undefined`.

   ```ts title="signup.ts"
   import { safeParsePhoneNumber, tryParsePhoneNumber } from '@madagascar-oss/phone';

   const result = safeParsePhoneNumber('035 12 345 67');
   if (!result.success) result.error.code; // 'UNKNOWN_OPERATOR'

   tryParsePhoneNumber('not a number'); // undefined
   ```

4. ### Check the result

   Error codes are the same in every language, so a form can show the same message whether the check ran in the browser or on a PHP server.

   ```ts title="signup.ts"
   import { MgError, parsePhoneNumber } from '@madagascar-oss/phone';

   try {
     parsePhoneNumber(userInput);
   } catch (error) {
     if (error instanceof MgError) console.log(error.code); // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>

  [playground](/mg-utils-docs/play/).
