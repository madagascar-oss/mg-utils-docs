## Utilisation de base

Le malgache lit les nombres de la plus petite unité à la plus grande. La partie la plus petite se relie à 10 par `ambin'ny`, à 20–90 et à 100 exactement par `amby`, à 200–900 et aux groupes plus grands par `sy`.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { spell } from '@mdgascar/words';

    spell(0); // 'aotra'
    spell(11); // "iraika ambin'ny folo"
    spell(21); // 'iraika amby roapolo'
    spell(101); // 'iraika amby zato'
    spell(205); // 'dimy sy roanjato'
    spell(348); // 'valo amby efapolo sy telonjato'
    spell(1960); // 'enimpolo sy sivinjato sy arivo'
    spell(2026); // 'enina amby roapolo sy roa arivo'
    spell(10000); // 'iray alina'
    spell(280000); // 'valo alina sy roa hetsy'
    spell(1000000); // 'iray tapitrisa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Words\NumberWords;

    NumberWords::spell(0); // 'aotra'
    NumberWords::spell(11); // "iraika ambin'ny folo"
    NumberWords::spell(21); // 'iraika amby roapolo'
    NumberWords::spell(101); // 'iraika amby zato'
    NumberWords::spell(205); // 'dimy sy roanjato'
    NumberWords::spell(348); // 'valo amby efapolo sy telonjato'

    NumberWords::spell(280000); // 'valo alina sy roa hetsy'
    NumberWords::spell(1000000); // 'iray tapitrisa'
    ```
  </TabItem>
</Tabs>

## Ordinaux

`spellOrdinal` écrit le rang : `faha` devant le nombre en lettres, `fah` devant une voyelle, et `voalohany` pour 1.

<Tabs syncKey="language">
  <TabItem label="JavaScript">

    ```ts
    import { spellOrdinal } from '@mdgascar/words';

    spellOrdinal(1); // 'voalohany'
    spellOrdinal(2); // 'faharoa'
    spellOrdinal(3); // 'fahatelo'
    spellOrdinal(4); // 'fahefatra'
    spellOrdinal(11); // "fahiraika ambin'ny folo"
    ```
  </TabItem>

    ```php
    NumberWords::spellOrdinal(4); // 'fahefatra'
    NumberWords::spellOrdinal(11); // "fahiraika ambin'ny folo"
    ```

## Relire des lettres

`parseWords` retrouve le nombre à partir des lettres. La casse et les espaces en trop ne comptent pas. `safeParseWords` renvoie l'erreur au lieu de la lever, et `tryParseWords` renvoie `undefined` (PHP : `safeParse`, `tryParse`).

<TryItBox module="words" variant="readWords" examples={['roa arivo', 'iraika amby roapolo', 'valo amby efapolo sy telonjato', 'telo faingo dimy']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { parseWords } from '@mdgascar/words';

    parseWords('roa arivo'); // 2000
    parseWords('Iraika amby roapolo'); // 21
    parseWords('telo faingo dimy'); // 3.5
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::parse('roa arivo')->value(); // 2000
    NumberWords::parse('Iraika amby roapolo')->value(); // 21
    NumberWords::parse('telo faingo dimy')->value(); // 3.5
    ```
  </TabItem>
</Tabs>

<Aside>La lecture n'arrondit jamais. Un nombre trop grand pour le langage lève `PRECISION_LOSS` ; demandez `{ as: 'text' }` (PHP : `->digits`) pour obtenir chaque chiffre en texte.</Aside>

## Grands nombres

Les règles n’ont pas de limite haute : `lavitrisa` (10⁹), le plus grand mot de groupe, prend un multiplicateur de toute taille. Un multiplicateur devant un mot de groupe forme une seule expression, reliée par `amby`. Chaque langage s’arrête seulement là où ses nombres cessent d’être exacts : `Number.MAX_SAFE_INTEGER` en JavaScript, `PHP_INT_MAX` en PHP.

<TryItBox module="words" input="1000000000" examples={['1000000', '1000000000', '2000000000']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(280000000); // 'valopolo amby roanjato tapitrisa'
    spell(1000000000); // 'iray lavitrisa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::spell(280000000); // 'valopolo amby roanjato tapitrisa'
    NumberWords::spell(1000000000); // 'iray lavitrisa'
    ```
  </TabItem>
</Tabs>

## Système traditionnel

Le malgache a aussi un nom pour chaque puissance de dix. Il ne sert pas dans l’écriture courante, mais les manuels d’apprentissage le donnent. Passez `system: 'traditional'` pour l’utiliser : chaque nom prend un seul chiffre, de 1 à 9, du plus petit au plus grand, reliés par `sy`. Sous 10 000, les deux systèmes écrivent les mêmes mots, et les décimales suivent le système choisi.

| Puissance | Nom | Puissance | Nom | Puissance | Nom |
| --- | --- | --- | --- | --- | --- |
| 10⁴ | `alina` | 10⁹ | `lavitrisa` | 10¹⁴ | `safatsiroafaharoa` |
| 10⁵ | `hetsy` | 10¹⁰ | `alinkisa` | 10¹⁵ | `tsitamboisafaharoa` |
| 10⁶ | `tapitrisa` | 10¹¹ | `tsipesimpesenina` | 10¹⁶ | `lavitrisafaharoa`\* |
| 10⁷ | `safatsiroa` | 10¹² | `tsitokotsiforohana` | 10¹⁷ | `alinkisafaharoa`\* |
| 10⁸ | `tsitamboisa` | 10¹³ | `tsihitanoanoa` | 10¹⁸ | `tsipesimpeseninafaharoa`\* |

\* Déduits de la règle de la source : `<nom>faharoa` (« le deuxième ») vaut ce nom × 10⁷.

<TryItBox module="words" input="30000000" option="traditional" examples={['30000000', '45000000']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(30000000); // 'telopolo tapitrisa'
    spell(30000000, { system: 'traditional' }); // 'telo safatsiroa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Words\NumberSystem;

    NumberWords::spell(30000000); // 'telopolo tapitrisa'
    NumberWords::spell(30000000, NumberSystem::Traditional); // 'telo safatsiroa'
    ```
  </TabItem>
</Tabs>

## Décimales

La partie entière vient d’abord, puis `faingo` (la virgule), puis les chiffres après la virgule lus comme un nombre entier. Chaque zéro juste après la virgule se dit `aotra`.

<TryItBox module="words" input="3.14" examples={['3.14', '0.5', '2.5', '12.75']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(3.14); // "telo faingo efatra ambin'ny folo"
    spell(0.5); // 'aotra faingo dimy'
    spell(12.75); // "roa ambin'ny folo faingo dimy amby fitopolo"
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::spell(3.14); // "telo faingo efatra ambin'ny folo"
    NumberWords::spell(0.5); // 'aotra faingo dimy'
    NumberWords::spell(12.75); // "roa ambin'ny folo faingo dimy amby fitopolo"
    ```
  </TabItem>
</Tabs>

<Aside title="PHP : declare(strict_types=1)">`NumberWords::spell()` garde chaque type tel quel : `spell(2.5)` donne `roa faingo dimy`. Déclarez tout de même `strict_types=1` dans vos fichiers : sans cela, PHP transforme sans prévenir un flottant passé à un paramètre `int` en entier, et `2.5` devient `2` avant que la bibliothèque le voie.</Aside>

## Erreurs

| Entrée | Code d’erreur |
| --- | --- |
| Ni un nombre fini ni du texte (`null`, `NaN`, `Infinity`) | `INVALID_TYPE` |
| Texte qui n’est pas décimal simple (`'1 500'`, `'-1'`, `'1e5'`) | `INVALID_FORMAT` |
| Inférieur à 0 | `OUT_OF_RANGE` |
| Au-delà du plus grand nombre exact du langage | `OUT_OF_RANGE` |
| `parseWords` : des lettres que `spell` n’écrit pas | `INVALID_FORMAT` |
| `parseWords` : un nombre trop grand pour le langage | `PRECISION_LOSS` |

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(-1); // throws MdgError, error.code === 'OUT_OF_RANGE'
    spell('1 500'); // throws MdgError, 'INVALID_FORMAT'
    spell(Number.MAX_SAFE_INTEGER + 1); // throws MdgError, 'OUT_OF_RANGE'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::spell(-1); // throws MdgUtilsException, ->errorCode === ErrorCode::OutOfRange
    NumberWords::spell(NAN); // throws MdgUtilsException, ErrorCode::InvalidType
    NumberWords::spell('1 500'); // throws MdgUtilsException, ErrorCode::InvalidFormat
    ```
  </TabItem>
</Tabs>

## Non pris en charge

Les nombres négatifs ne sont pas écrits en lettres : aucune source n'en épelle un.
