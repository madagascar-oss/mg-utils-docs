## Fametrahana amin’ny Composer

<Steps>

1. ### Takio ny fonosana

   ```sh title="Terminal"
   composer require mdgascar/mdg-utils
   ```

2. ### Ampiasao ny môdily iray

   Kilasy ao ambanin’ny `Mdgascar\MdgUtils` ny môdily tsirairay. Vakio ny laharana na ahoana na ahoana fomba nanoratana azy ary soraty indray.

   ```php title="signup.php"
   <?php

   require __DIR__ . '/vendor/autoload.php';

   use Mdgascar\MdgUtils\Phone\PhoneNumber;
   use Mdgascar\MdgUtils\Phone\PhoneNumberFormat;

   $phone = PhoneNumber::parse('034 12 345 67');
   $phone->operator->displayName(); // 'Telma'
   $phone->format(PhoneNumberFormat::International); // '+261 34 12 345 67'
   ```

3. ### Tantano ny fampidirana diso

   Manipy `MdgUtilsException` ny `parse()`. Mamerina ny kaody hadisoana tsy misy fanipazana ny `safeParse()`, mamerina `null` ny `tryParse()`.

   ```php title="signup.php"
   use Mdgascar\MdgUtils\ErrorCode;
   use Mdgascar\MdgUtils\Phone\PhoneNumber;

   $result = PhoneNumber::safeParse('035 12 345 67');
   $result->success;           // false
   $result->error?->errorCode; // ErrorCode::UnknownOperator

   PhoneNumber::tryParse('not a number'); // null
   ```

4. ### Raiso mitovy ny hadisoan’ny môdily rehetra

   Manipy `MdgUtilsException` ny môdily rehetra; ny `errorCode` ao aminy dia ilay kaody mitovy amin’ny an’ny JavaScript.

   ```php title="signup.php"
   use Mdgascar\MdgUtils\MdgUtilsException;

   try {
       PhoneNumber::parse($userInput);
   } catch (MdgUtilsException $exception) {
       echo $exception->errorCode->value; // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>
