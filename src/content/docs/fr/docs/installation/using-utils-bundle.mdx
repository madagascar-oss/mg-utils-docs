## Installer le paquet utils

Choisissez-le quand une application utilise plusieurs modules. Les bundlers ne gardent que les fonctions importées : les modules inutilisés n’atteignent pas vos utilisateurs.

<Steps>

1. ### Installer le paquet

   ```sh title="Terminal"
   npm install @mdgascar/utils
   ```

2. ### Importer depuis un seul endroit

   ```ts title="invoice.ts"
   import { ariaryToWords, formatAriary, formatDate, numberToWords } from '@mdgascar/utils';

   formatAriary(1500); // 'Ar 1 500'
   ariaryToWords(1500); // 'dimanjato sy arivo ariary'
   formatDate('2026-11-23', 'full'); // 'Alatsinainy 23 Novambra 2026'
   numberToWords(21); // 'iraika amby roapolo'
   ```

3. ### Intercepter les erreurs de tous les modules de la même façon

   Tous les modules lèvent la même `MdgError` : un seul `catch` suffit.

   ```ts title="invoice.ts"
   import { MdgError, parseAriary } from '@mdgascar/utils';

   try {
     parseAriary('1,500');
   } catch (error) {
     if (error instanceof MdgError) console.log(error.code); // 'INVALID_FORMAT'
   }
   ```

</Steps>
