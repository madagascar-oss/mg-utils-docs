## Phone

| Method                                                    | Returns                         | Throws                               |
| --------------------------------------------------------- | ------------------------------- | ------------------------------------ |
| `Phone\PhoneNumber::parse(string $input)`                 | `PhoneNumber`                   | `INVALID_FORMAT`, `UNKNOWN_OPERATOR` |
| `Phone\PhoneNumber::safeParse(mixed $input)`              | `SafeParseResult<PhoneNumber>`  | never                                |
| `Phone\PhoneNumber::tryParse(mixed $input)`              | `?PhoneNumber`                  | never                                |
| `Phone\PhoneNumber::isValid(mixed $input)`                | `bool`                          | never                                |
| `$phone->format(PhoneNumberFormat $format)`               | `string`                        | never                                |
| `$phone->e164`, `$phone->nationalNumber`, `$phone->operator` | `string`, `string`, `Operator` | —                                    |
| `Phone\Operator::displayName()`                           | `string`                        | never                                |

Enums: `PhoneNumberFormat` (`E164`, `International`, `National`), `Operator` (`Orange`, `Airtel`, `Telma`, `Blueline`).

## Shared

| Class                       | Purpose                                                          |
| --------------------------- | ---------------------------------------------------------------- |
| `MdgUtilsException`          | Thrown on bad input; `->errorCode` is an `ErrorCode`             |
| `ErrorCode`                 | `InvalidType`, `OutOfRange`, `InvalidFormat`, `UnknownOperator`  |
| `SafeParseResult`           | `->success`, `->data`, `->error` from every `safeParse()`        |
| `Spec::VERSION`             | The spec version this package implements                         |

Wrong argument types raise PHP's own `TypeError`; the spec reports them as `INVALID_TYPE`.
