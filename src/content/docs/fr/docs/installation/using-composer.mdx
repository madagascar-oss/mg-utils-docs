## Installer avec Composer

<Steps>

1. ### Ajouter le paquet

   ```sh title="Terminal"
   composer require mdgascar/mdg-utils
   ```

2. ### Utiliser un module

   Chaque module est une classe sous `Mdgascar\MdgUtils`. Lisez un numéro écrit de n’importe quelle façon courante et formatez-le.

   ```php title="signup.php"
   <?php

   require __DIR__ . '/vendor/autoload.php';

   use Mdgascar\MdgUtils\Phone\PhoneNumber;
   use Mdgascar\MdgUtils\Phone\PhoneNumberFormat;

   $phone = PhoneNumber::parse('034 12 345 67');
   $phone->operator->displayName(); // 'Yas Madagascar'
   $phone->format(PhoneNumberFormat::International); // '+261 34 12 345 67'
   ```

3. ### Gérer les saisies invalides

   `parse()` lève une `MdgUtilsException`. `safeParse()` renvoie le code d’erreur sans exception, `tryParse()` renvoie `null`.

   ```php title="signup.php"
   use Mdgascar\MdgUtils\ErrorCode;
   use Mdgascar\MdgUtils\Phone\PhoneNumber;

   $result = PhoneNumber::safeParse('031 12 345 67');
   $result->success;           // false
   $result->error?->errorCode; // ErrorCode::UnknownOperator

   PhoneNumber::tryParse('not a number'); // null
   ```

4. ### Intercepter les erreurs de tous les modules de la même façon

   Tous les modules lèvent `MdgUtilsException` ; son `errorCode` est le même code que celui de JavaScript.

   ```php title="signup.php"
   use Mdgascar\MdgUtils\MdgUtilsException;

   try {
       PhoneNumber::parse($userInput);
   } catch (MdgUtilsException $exception) {
       echo $exception->errorCode->value; // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>
