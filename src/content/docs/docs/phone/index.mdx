## Basic usage

Spaces, dashes, dots, parentheses, `+261`, `00261` and the leading `0` are all accepted.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { parsePhone } from '@mdgascar/phone';

    parsePhone('034 12 345 67');
    // { e164: '+261341234567', nationalNumber: '341234567', operator: 'yas', type: 'mobile', area: null }

    parsePhone('+261 32 12 345 67').operator; // 'orange'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Phone\PhoneNumber;

    $phone = PhoneNumber::parse('034 12 345 67');
    $phone->e164;           // '+261341234567'
    $phone->nationalNumber; // '341234567'
    $phone->operator;       // Operator::Yas

    PhoneNumber::parse('+261 32 12 345 67')->operator; // Operator::Orange
    ```
  </TabItem>
</Tabs>

## Fixed lines

Fixed-line numbers are read too: `020` for the Yas (Telecom Malagasy) network and `022` for Gulfsat. A parsed number tells its `type`, and the town of a geographic number when the national plan lists it.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    parsePhone('020 22 421 19').type; // 'fixed'
    parsePhone('020 22 421 19').area; // { name: 'Antananarivo', province: 'Antananarivo' }
    parsePhone('034 12 345 67').type; // 'mobile'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    PhoneNumber::parse('020 22 421 19')->type;        // PhoneLineType::Fixed
    PhoneNumber::parse('020 22 421 19')->area?->name; // 'Antananarivo'
    PhoneNumber::parse('034 12 345 67')->type;        // PhoneLineType::Mobile
    ```
  </TabItem>
</Tabs>

## Formatting

Three formats: `e164` for storage and APIs, `international` for people abroad, `national` for people in Madagascar.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { formatPhone } from '@mdgascar/phone';

    formatPhone('034 12 345 67', 'e164'); // '+261341234567'
    formatPhone('034 12 345 67', 'international'); // '+261 34 12 345 67'
    formatPhone('+261341234567', 'national'); // '034 12 345 67'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Phone\PhoneNumber;
    use Mdgascar\MdgUtils\Phone\PhoneNumberFormat;

    $phone = PhoneNumber::parse('034 12 345 67');
    $phone->format(PhoneNumberFormat::E164);          // '+261341234567'
    $phone->format(PhoneNumberFormat::International); // '+261 34 12 345 67'
    $phone->format(PhoneNumberFormat::National);      // '034 12 345 67'
    ```
  </TabItem>
</Tabs>

## Operator names

<Tabs syncKey="language">
  <TabItem label="JavaScript">

    ```ts
    OPERATOR_NAMES[parsePhone('034 12 345 67').operator]; // 'Yas Madagascar'
    OPERATOR_NAMES.orange; // 'Orange Madagascar'
    ```

  </TabItem>
  <TabItem label="PHP">

    ```php
    Operator::Orange->displayName(); // 'Orange Madagascar'
    ```

## Checking user input

`isValid` never throws. `safeParse` tells you why a number was rejected, `tryParse` gives you the number or nothing.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { isValidPhone, safeParsePhone, tryParsePhone } from '@mdgascar/phone';

    isValidPhone('031 12 345 67'); // false

    const result = safeParsePhone('031 12 345 67');
    if (!result.success) result.error.code; // 'UNKNOWN_OPERATOR'

    tryParsePhone('031 12 345 67'); // undefined
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    PhoneNumber::isValid('031 12 345 67'); // false

    $result = PhoneNumber::safeParse('031 12 345 67');
    $result->error?->errorCode; // ErrorCode::UnknownOperator

    PhoneNumber::tryParse('031 12 345 67'); // null
    ```
  </TabItem>
</Tabs>

## Errors

| Input                                              | Error code         |
| -------------------------------------------------- | ------------------ |
| Not a string                                       | `INVALID_TYPE`     |
| Not a Malagasy phone number (wrong length, letters) | `INVALID_FORMAT` |
| Prefix not assigned to an operator (`031`)  | `UNKNOWN_OPERATOR` |
