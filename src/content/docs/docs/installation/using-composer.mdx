## Installing with Composer

<Steps>

1. ### Require the package

   ```sh title="Terminal"
   composer require madagascar-oss/mg-utils
   ```

2. ### Use a module

   Each module is a class under `Madagascar\MgUtils`. Read a number written in any common way and format it.

   ```php title="signup.php"
   <?php

   require __DIR__ . '/vendor/autoload.php';

   use Madagascar\MgUtils\Phone\PhoneNumber;
   use Madagascar\MgUtils\Phone\PhoneNumberFormat;

   $phone = PhoneNumber::parse('034 12 345 67');
   $phone->operator->displayName(); // 'Telma'
   $phone->format(PhoneNumberFormat::International); // '+261 34 12 345 67'
   ```

3. ### Handle bad input

   `parse()` throws `MgUtilsException`. `safeParse()` returns the error code without throwing, `tryParse()` returns `null`.

   ```php title="signup.php"
   use Madagascar\MgUtils\ErrorCode;
   use Madagascar\MgUtils\Phone\PhoneNumber;

   $result = PhoneNumber::safeParse('035 12 345 67');
   $result->success;           // false
   $result->error?->errorCode; // ErrorCode::UnknownOperator

   PhoneNumber::tryParse('not a number'); // null
   ```

4. ### Catch errors from every module the same way

   Every module throws `MgUtilsException`; its `errorCode` is the same code JavaScript reports.

   ```php title="signup.php"
   use Madagascar\MgUtils\MgUtilsException;

   try {
       PhoneNumber::parse($userInput);
   } catch (MgUtilsException $exception) {
       echo $exception->errorCode->value; // 'INVALID_FORMAT' | 'UNKNOWN_OPERATOR' | …
   }
   ```

</Steps>

  [mg-utils-php](https://github.com/madagascar-oss/mg-utils-php) with a Composer `vcs` repository.
</Aside>
