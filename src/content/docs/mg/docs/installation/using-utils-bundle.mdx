## Fametrahana ny fonosana utils

Safidio ity raha môdily maromaro no ampiasain’ny rindranasa. Ny asa ampidirinao ihany no tazonin’ny bundler, ka tsy tonga any amin’ny mpampiasa ny môdily tsy ampiasaina.

<Steps>

1. ### Apetraho ny fonosana

   ```sh title="Terminal"
   npm install @mdgascar/utils
   ```

2. ### Ampidiro avy amin’ny toerana iray

   ```ts title="invoice.ts"
   import { ariaryToWords, formatAriary, formatDate, numberToWords } from '@mdgascar/utils';

   formatAriary(1500); // 'Ar 1 500'
   ariaryToWords(1500); // 'dimanjato sy arivo ariary'
   formatDate('2026-11-23', 'full'); // 'Alatsinainy 23 Novambra 2026'
   numberToWords(21); // 'iraika amby roapolo'
   ```

3. ### Raiso mitovy ny hadisoan’ny môdily rehetra

   Manipy `MdgError` mitovy ny môdily rehetra, ka `catch` iray dia ampy ho azy rehetra.

   ```ts title="invoice.ts"
   import { MdgError, parseAriary } from '@mdgascar/utils';

   try {
     parseAriary('1,500');
   } catch (error) {
     if (error instanceof MdgError) console.log(error.code); // 'INVALID_FORMAT'
   }
   ```

</Steps>

<Aside type="tip" title="Misy olana ve?">
  Andramo mivantana ny asa rehetra, amin’ny JavaScript sy PHP, ao amin’ny [toerana fanandramana](/mdg-utils-docs/mg/play/).
</Aside>
