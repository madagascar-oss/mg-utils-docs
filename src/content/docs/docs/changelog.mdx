Each entry is a spec version: the rules, data and test vectors every package implements. Package releases (npm, Packagist) follow it and list their own changes in their `CHANGELOG.md`. See [Versioning](/mdg-utils-docs/docs/versioning/) for what each kind of number means.

**Breaking** marks an output that changes for an input that worked before.

## 0.8.0 (2026-11-27)

- **Breaking**: function names now use the domain's words: `spell` (was `numberToWords`), `spellAriary` (`ariaryToWords`), `parsePhone`, `safeParsePhone`, `tryParsePhone`, `isValidPhone`, `formatPhone` (were `…PhoneNumber`), `monthName` (`getMonthName`), `weekdayName` (`getWeekdayName`). PHP: `NumberWords::spell()` takes an int, a float or text; `->spell()` replaces `->toWords()`. Outputs are unchanged.
- `words`: Decimal text is read exactly: `spell('2000000000000000.9')` → `roa tapitrisa lavitrisa faingo sivy`, where the number has already lost its `.9`. Text that is not plain decimal is `INVALID_FORMAT`; `'12'` reads `roa ambin'ny folo` instead of `INVALID_TYPE`.
- `words`: In the traditional system, a number of 10¹⁹ or more (text only) is written in the standard system.
- `ariary`: `spellAriary` takes the same decimal text.

## 0.7.0 (2026-11-27)

- `words`: New option `system: 'traditional'`: one name per power of ten, each with a single digit. `30 000 000` → `telo safatsiroa` instead of `telopolo tapitrisa`. 10⁷–10¹⁵ come from Assimil, and 10¹⁶–10¹⁸ are derived from its `faharoa` rule. The standard system stays the default, and its output is unchanged.
- `ariary`: `ariaryToWords` takes the same `system` option.

## 0.6.0 (2026-11-26)

- `phone`: New prefix `035` for Airtel Madagascar, on sale since 22 June 2026: `035 12 345 67` → operator `airtel` instead of `UNKNOWN_OPERATOR`.
- `phone`: **Breaking**: Telma is now Yas Madagascar (since 26 November 2024). The operator id `telma` is now `yas`, named `Yas Madagascar`; PHP `Operator::Telma` is now `Operator::Yas`.
- `phone`: `036`, announced by Yas without a published source yet, stays `UNKNOWN_OPERATOR` and is listed under Waiting for a source.

## 0.5.0 (2026-11-26)

- `words`: **Breaking**: spells numbers of any size. `lavitrisa` takes a count of any size, so 10¹² is `arivo lavitrisa` instead of `OUT_OF_RANGE`. Each language stops at its largest exact number.
- `words`: Decimals, read with `faingo`: `3.14` → `telo faingo efatra ambin'ny folo`, `0.008` → `aotra faingo aotra aotra valo`. PHP adds `NumberWords::fromFloat()`.
- `words`: New section listing what waits for a source or an expert: negative numbers, and the old names for 10⁷ and above.
- `ariary`: **Breaking**: no more 999 999 999 999 cap, and decimal amounts after a comma: `Ar 1 500,5`. PHP adds `Ariary::fromFloat()`; `$amount` is `int|float`.
- `ariary`: **Breaking**: `parseAriary('1,500')` reads 1.5 instead of throwing `INVALID_FORMAT`. For English-style text, pass `{ grouping: 'comma', decimal: 'dot' }`.
- `ariary`: New `grouping: comma` and `decimal` options for formatting and the three parsers; the defaults stay Malagasy.
- `ariary`: **Breaking**: FMG conversion is exact in decimal and accepts any francs: `fmgToAriary(7501)` → `1500.2` instead of `OUT_OF_RANGE`; `ariaryToFmg(0.07)` → `0.35`.
- `ariary`: Points under review: the default reading of `1,500`, rounding of very long decimals, and formatted text longer than the 32-character reading limit.

## 0.4.0 (2026-11-25)

- `words`: **Breaking**: a count of one is bare only for `arivo`: `10 000` → `iray alina`, `1 000 000` → `iray tapitrisa`; `1 000` stays `arivo`.

## 0.3.0 (2026-11-25)

- `words`: **Breaking**: hundreds from 200 join with `sy` at every size (`205` → `dimy sy roanjato`), and 11–19 use `ambin'ny` (`11` → `iraika ambin'ny folo`).

## 0.2.0 (2026-11-24)

- `spec`: **Breaking**: modules moved to `modules/` and schemas to `schemas/`. Adds the ariary and date modules.

## 0.1.0 (2026-11-23)

- `spec`: First spec: shared error codes and schemas, the words and phone modules.
