Everything is under the `Mdgascar\MdgUtils` namespace. Errors throw `MdgUtilsException`; read `$exception->errorCode` (an `ErrorCode`), the same code in every language.

## Number words

| Method                                                              | Returns                        | Error codes                             |
| ------------------------------------------------------------------- | ------------------------------ | --------------------------------------- |
| `Words\NumberWords::spell(int\|float\|string $n, NumberSystem)`     | `string`                       | `OUT_OF_RANGE`, `INVALID_FORMAT`        |
| `Words\NumberWords::spellOrdinal(int\|string $n, NumberSystem)`     | `string`                       | `OUT_OF_RANGE`, `INVALID_FORMAT`        |
| `Words\NumberWords::parse(string $words)`                           | `ExactNumber`                  | `INVALID_FORMAT`, `AMBIGUOUS`           |
| `Words\NumberWords::safeParse(mixed $words)`                        | `SafeParseResult<ExactNumber>` | never                                   |
| `Words\NumberWords::tryParse(mixed $words)`                         | `?ExactNumber`                 | never                                   |
| `ExactNumber->value()`                                              | `int\|float`                   | `PRECISION_LOSS`                        |
| `ExactNumber->digits`                                               | `string`                       | never                                   |

Enum: `Words\NumberSystem` (`Standard`, `Traditional`).

## Date

| Method                                                       | Returns                        | Error codes                                     |
| ------------------------------------------------------------ | ------------------------------ | ----------------------------------------------- |
| `Date\MalagasyDate::fromString(string $isoDate)`             | `MalagasyDate`                 | `INVALID_FORMAT`, `OUT_OF_RANGE`                |
| `Date\MalagasyDate::fromParts(int $year, int $month, int $day)` | `MalagasyDate`              | `OUT_OF_RANGE`                                  |
| `Date\MalagasyDate::fromDateTime(DateTimeInterface $date)`   | `MalagasyDate`                 | `OUT_OF_RANGE`                                  |
| `Date\MalagasyDate::parse(string $text, ?DateStyle)`         | `MalagasyDate`                 | `INVALID_FORMAT`, `OUT_OF_RANGE`, `AMBIGUOUS`   |
| `Date\MalagasyDate::safeParse(mixed $text, ?DateStyle)`      | `SafeParseResult<MalagasyDate>` | never                                          |
| `Date\MalagasyDate::tryParse(mixed $text, ?DateStyle)`       | `?MalagasyDate`                | never                                           |
| `$date->format(DateStyle $style)`                            | `string`                       | never                                           |
| `Date\MalagasyDate::monthName(int $month, NameWidth)`        | `string`                       | `OUT_OF_RANGE`                                  |

Enums: `DateStyle` (`Long`, `Full`, `Medium`, `Short`, `Numeric`), `NameWidth` (`Wide`, `Abbreviated`).

`$date->isoWeekday()` returns the ISO weekday (Monday 1, Sunday 7).

## Shared

| Class               | Purpose                                                                                       |
| ------------------- | --------------------------------------------------------------------------------------------- |
| `MdgUtilsException` | Thrown on bad input; `->errorCode` is an `ErrorCode`                                          |
| `ErrorCode`         | `InvalidType`, `OutOfRange`, `InvalidFormat`, `UnknownOperator`, `PrecisionLoss`, `Ambiguous` |
| `SafeParseResult`   | `->success`, `->data`, `->error` from every `safeParse()`                                     |
| `ExactNumber`       | A number read from text: `->digits`, and `value()` when an int or float holds it exactly      |
| `Spec::VERSION`     | The spec version this package implements                                                      |

Wrong argument types raise PHP's own `TypeError`; the spec reports them as `INVALID_TYPE`.
