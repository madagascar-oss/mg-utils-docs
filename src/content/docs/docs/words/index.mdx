## Basic usage

Malagasy reads numbers from the smallest part up. The smaller part joins 10 with `ambin'ny`, 20–90 and exactly 100 with `amby`, and 200–900 and every larger group with `sy`.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { spell } from '@mdgascar/words';

    spell(0); // 'aotra'
    spell(11); // "iraika ambin'ny folo"
    spell(21); // 'iraika amby roapolo'
    spell(101); // 'iraika amby zato'
    spell(205); // 'dimy sy roanjato'
    spell(348); // 'valo amby efapolo sy telonjato'
    spell(1960); // 'enimpolo sy sivinjato sy arivo'
    spell(2026); // 'enina amby roapolo sy roa arivo'
    spell(10000); // 'iray alina'
    spell(280000); // 'valo alina sy roa hetsy'
    spell(1000000); // 'iray tapitrisa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Words\NumberWords;

    NumberWords::spell(0); // 'aotra'
    NumberWords::spell(11); // "iraika ambin'ny folo"
    NumberWords::spell(21); // 'iraika amby roapolo'
    NumberWords::spell(101); // 'iraika amby zato'
    NumberWords::spell(205); // 'dimy sy roanjato'
    NumberWords::spell(348); // 'valo amby efapolo sy telonjato'
    NumberWords::spell(1960); // 'enimpolo sy sivinjato sy arivo'
    NumberWords::spell(2026); // 'enina amby roapolo sy roa arivo'
    NumberWords::spell(10000); // 'iray alina'
    NumberWords::spell(280000); // 'valo alina sy roa hetsy'
    NumberWords::spell(1000000); // 'iray tapitrisa'
    ```
  </TabItem>
</Tabs>

## Large numbers

There is no upper limit in the rules: `lavitrisa` (10⁹), the largest group word, takes a count of any size, written with the same rules. Each language stops only where its numbers stop being exact: `Number.MAX_SAFE_INTEGER` in JavaScript, `PHP_INT_MAX` in PHP.

## Traditional system

Malagasy also has a name for every power of ten. It is not used in everyday writing, but learner books list it. Pass `system: 'traditional'` to use it: each name takes a single digit, 1 to 9, smallest part first, joined by `sy`. Below 10 000 both systems write the same words, and decimals follow the system you choose.

| Power | Name | Power | Name | Power | Name |
| --- | --- | --- | --- | --- | --- |
| 10⁴ | `alina` | 10⁹ | `lavitrisa` | 10¹⁴ | `safatsiroafaharoa` |
| 10⁵ | `hetsy` | 10¹⁰ | `alinkisa` | 10¹⁵ | `tsitamboisafaharoa` |
| 10⁶ | `tapitrisa` | 10¹¹ | `tsipesimpesenina` | 10¹⁶ | `lavitrisafaharoa`\* |
| 10⁷ | `safatsiroa` | 10¹² | `tsitokotsiforohana` | 10¹⁷ | `alinkisafaharoa`\* |
| 10⁸ | `tsitamboisa` | 10¹³ | `tsihitanoanoa` | 10¹⁸ | `tsipesimpeseninafaharoa`\* |

\* Derived from the source's rule: `<name>faharoa` ("the second") is that name × 10⁷.

<TryItBox module="words" input="30000000" option="traditional" examples={['30000000', '45000000', '12345678901', '1000000000000000']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(30000000); // 'telopolo tapitrisa'
    spell(30000000, { system: 'traditional' }); // 'telo safatsiroa'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Words\NumberSystem;

    NumberWords::spell(30000000); // 'telopolo tapitrisa'
    NumberWords::spell(30000000, NumberSystem::Traditional); // 'telo safatsiroa'
    ```
  </TabItem>
</Tabs>

## Decimals

The whole part comes first, then `faingo` (the comma), then the digits after the point read as a whole number. Each zero right after the point is `aotra`.

<TryItBox module="words" input="3.14" examples={['3.14', '18.3', '0.5', '1.05', '0.008', '12.75', '1234.5678']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(3.14); // "telo faingo efatra ambin'ny folo"
    spell(18.3); // "valo ambin'ny folo faingo telo"
    spell(0.5); // 'aotra faingo dimy'
    spell(1.05); // 'iray faingo aotra dimy'
    spell(0.008); // 'aotra faingo aotra aotra valo'
    spell(12.75); // "roa ambin'ny folo faingo dimy amby fitopolo"
    spell(1.0); // 'iray' (a whole number has no faingo)
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::spell(3.14); // "telo faingo efatra ambin'ny folo"
    NumberWords::spell(18.3); // "valo ambin'ny folo faingo telo"
    NumberWords::spell(0.5); // 'aotra faingo dimy'
    NumberWords::spell(1.05); // 'iray faingo aotra dimy'
    NumberWords::spell(0.008); // 'aotra faingo aotra aotra valo'
    NumberWords::spell(12.75); // "roa ambin'ny folo faingo dimy amby fitopolo"
    NumberWords::spell(1.0); // 'iray' (a whole number has no faingo)
    ```
  </TabItem>
</Tabs>

<Aside>The decimals are those of the number value. `1.50` is the number `1.5`, and `0.1 + 0.2` is `0.30000000000000004` in floating point, so it reads that way.</Aside>

## Exact digits

A number value keeps about 15 to 17 significant digits, in JavaScript and in PHP floats alike. So a large number with decimals has already lost digits before any function sees it: `2_000_000_000_000_000.9` is stored as `2000000000000001`. Pass the digits as text to read every one of them exactly, at any size:

<TryItBox module="words" input="2000000000000000.9" examples={['2000000000000000.9', '1000000000000000000.111', '1.50', '1 500']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(2_000_000_000_000_000.9); // 'iray sy roa tapitrisa lavitrisa' (the float)
    spell('2000000000000000.9'); // 'roa tapitrisa lavitrisa faingo sivy'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::spell(2_000_000_000_000_000.9); // 'iray sy roa tapitrisa lavitrisa' (the float)
    NumberWords::spell('2000000000000000.9'); // 'roa tapitrisa lavitrisa faingo sivy'
    ```
  </TabItem>
</Tabs>

Text is plain digits with an optional `.` and decimals, at most 100 characters. Spaces, separators, signs and exponents are `INVALID_FORMAT`: to read amounts typed by users, such as `Ar 1 500`, use the ariary module. Leading zeros and trailing decimal zeros are dropped, so `'1.50'` reads like `1.5`.

<Aside title="PHP: declare(strict_types=1)">`NumberWords::spell()` keeps each type as it is: `spell(2.5)` is `roa faingo dimy`. Declare `strict_types=1` in your files anyway: without it, PHP quietly turns a float passed to any `int` parameter into an int, so `2.5` becomes `2` before the library sees it.</Aside>

## Errors

| Input | Error code |
| --- | --- |
| Not a finite number or text (`null`, `NaN`, `Infinity`) | `INVALID_TYPE` |
| Text that is not plain decimal (`'1 500'`, `'-1'`, `'1e5'`) | `INVALID_FORMAT` |
| Below 0 | `OUT_OF_RANGE` |
| Above the largest exact number of the language | `OUT_OF_RANGE` |

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    spell(-1); // throws MdgError, error.code === 'OUT_OF_RANGE'
    spell('1 500'); // throws MdgError, 'INVALID_FORMAT'
    spell(Number.MAX_SAFE_INTEGER + 1); // throws MdgError, 'OUT_OF_RANGE'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    NumberWords::spell(-1); // throws MdgUtilsException, ->errorCode === ErrorCode::OutOfRange
    NumberWords::spell(NAN); // throws MdgUtilsException, ErrorCode::InvalidType
    NumberWords::spell('1 500'); // throws MdgUtilsException, ErrorCode::InvalidFormat
    ```
  </TabItem>
</Tabs>
