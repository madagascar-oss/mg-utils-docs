## Fanoratana

Isa ny vola, feno na misy faingo, tsy misy fetra ambony ao amin’ny fitsipika. Ny arivo dia sarahina amin’ny elanelana tsy tapaka (na teboka), ary ny faingo no mialoha ny tarehimarika aorian’ny faingo. Tsy mpanasaraka arivo mihitsy ny faingo.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { formatAriary } from '@mdgascar/ariary';

    formatAriary(1500); // 'Ar 1 500'
    formatAriary(1500.5); // 'Ar 1 500,5'
    formatAriary(2_026_000, { grouping: 'dot' }); // 'Ar 2.026.000'
    formatAriary(1234567.89, { grouping: 'dot' }); // 'Ar 1.234.567,89'
    formatAriary(1500, { symbolPosition: 'after' }); // '1 500 Ar'
    formatAriary(1_000_000_000_000); // 'Ar 1 000 000 000 000'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Ariary\Ariary;
    use Mdgascar\MdgUtils\Ariary\Grouping;
    use Mdgascar\MdgUtils\Ariary\SymbolPosition;

    Ariary::fromInt(1500)->format(); // 'Ar 1 500'
    Ariary::fromFloat(1500.5)->format(); // 'Ar 1 500,5'
    Ariary::fromInt(2_026_000)->format(Grouping::Dot); // 'Ar 2.026.000'
    Ariary::fromFloat(1234567.89)->format(Grouping::Dot); // 'Ar 1.234.567,89'
    Ariary::fromInt(1500)->format(position: SymbolPosition::After); // '1 500 Ar'
    Ariary::fromInt(1_000_000_000_000)->format(); // 'Ar 1 000 000 000 000'
    ```
  </TabItem>
</Tabs>

<Aside>Elanelana tsy tapaka (U+00A0) ireo elanelana ao amin’ny valiny, ka tsy tapaka amin’ny andalana roa mihitsy ny vola.</Aside>

## Famakiana ny vola nosoratan’ny mpampiasa

`Ar 1 500`, `1.500 Ar`, `MGA 1500` ary `1 500` dia vakiana ho 1500 avokoa, ary ny `1 500,50 Ar` ho 1500.5. Lavina ny marika (+, -), sy ny teboka ampiasaina ho faingo.

<TryItBox module="ariary" input="1 500,50 Ar" examples={['1 500,50 Ar', '1.234.567,89', 'Ar 0,25', '1,500', '1,5,0', '-1 500', 'Ar 1 500 Ar']} />

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { parseAriary, safeParseAriary, tryParseAriary } from '@mdgascar/ariary';

    parseAriary('1.500 Ar'); // 1500
    parseAriary('MGA 1500'); // 1500
    parseAriary('1 500,50 Ar'); // 1500.5
    parseAriary('1,500'); // 1.5 (the comma is the decimal separator)

    tryParseAriary('1.5'); // undefined: a dot is not a decimal point by default
    const result = safeParseAriary('1.5');
    if (!result.success) result.error.code; // 'INVALID_FORMAT'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    Ariary::parse('1.500 Ar')->amount; // 1500
    Ariary::parse('MGA 1500')->amount; // 1500
    Ariary::parse('1 500,50 Ar')->amount; // 1500.5
    Ariary::parse('1,500')->amount; // 1.5 (the comma is the decimal separator)

    Ariary::tryParse('1.5'); // null: a dot is not a decimal point by default
    Ariary::safeParse('1.5')->error?->errorCode; // ErrorCode::InvalidFormat
    ```
  </TabItem>
</Tabs>

<Aside type="caution">Raha tsy misy safidy, ny `1,500` dia vakiana ho **1,5**: eto Madagasikara ny faingo no manasaraka ny tarehimarika aorian’ny faingo. Ny soratra amin’ny fomba anglisy, izay midika arivo sy dimanjato ny `1,500`, dia ho vakiana in-1000 kely loatra. Raha mety ho toy izany ny soratra ampidirina, lazao amin’ireo safidy etsy ambany. Io fomba io dia mbola hojerena indray, jereo ny fitsipika.</Aside>

## Fomba hafa

Ny safidy rehetra dia araka ny fomba malagasy raha tsy misy. Ho an’ny soratra amin’ny fomba hafa, omeo ny `grouping` sy ny `decimal`: tsy maminavina mihitsy ny tranomboky. Tsy maintsy samy hafa ireo tarehintsoratra roa ireo.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    formatAriary(1500.5, { grouping: 'comma', decimal: 'dot' }); // 'Ar 1,500.5'
    parseAriary('1,500.50', { grouping: 'comma', decimal: 'dot' }); // 1500.5
    parseAriary('1,500', { grouping: 'comma', decimal: 'dot' }); // 1500
    formatAriary(1500, { grouping: 'comma' }); // throws MdgError INVALID_TYPE: same as the decimal comma
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    use Mdgascar\MdgUtils\Ariary\DecimalSeparator;

    Ariary::fromFloat(1500.5)->format(Grouping::Comma, decimal: DecimalSeparator::Dot); // 'Ar 1,500.5'
    Ariary::parse('1,500.50', Grouping::Comma, DecimalSeparator::Dot)->amount; // 1500.5
    Ariary::parse('1,500', Grouping::Comma, DecimalSeparator::Dot)->amount; // 1500
    Ariary::fromInt(1500)->format(Grouping::Comma); // throws MdgUtilsException, ErrorCode::InvalidType
    ```
  </TabItem>
</Tabs>

## Vola an-teny

Ho an’ny rosia sy seky: ny vola an-teny malagasy arahin’ny `ariary`. Ny tarehimarika aorian’ny faingo dia manaraka ny `faingo`.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { ariaryToWords } from '@mdgascar/ariary';

    ariaryToWords(1500); // 'dimanjato sy arivo ariary'
    ariaryToWords(25_000); // 'dimy arivo sy roa alina ariary'
    ariaryToWords(1500.5); // 'dimanjato sy arivo faingo dimy ariary'
    ariaryToWords(1_000_000_000_000); // 'arivo lavitrisa ariary'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    Ariary::fromInt(1500)->toWords(); // 'dimanjato sy arivo ariary'
    Ariary::fromInt(25_000)->toWords(); // 'dimy arivo sy roa alina ariary'
    Ariary::fromFloat(1500.5)->toWords(); // 'dimanjato sy arivo faingo dimy ariary'
    Ariary::fromInt(1_000_000_000_000)->toWords(); // 'arivo lavitrisa ariary'
    ```
  </TabItem>
</Tabs>

## Iraimbilanja taloha (FMG)

5 FMG = 1 Ar. Marina tanteraka ny fanovana, ka ny FMG tsy zaraina amin’ny 5 dia manome ariary misy faingo, tsy misy fihodinana diso.

<Tabs syncKey="language">
  <TabItem label="JavaScript">
    ```ts
    import { ariaryToFmg, fmgToAriary, formatFmg } from '@mdgascar/ariary';

    fmgToAriary(7500); // 1500
    fmgToAriary(7501); // 1500.2
    ariaryToFmg(1500); // 7500
    ariaryToFmg(0.07); // 0.35 (exact, never 0.35000000000000003)
    formatFmg(7500); // 'Fmg 7 500'
    formatFmg(7500.5); // 'Fmg 7 500,5'
    ```
  </TabItem>
  <TabItem label="PHP">
    ```php
    Ariary::fromFmg(7500)->amount; // 1500
    Ariary::fromFmg(7501)->amount; // 1500.2
    Ariary::fromInt(1500)->toFmg(); // 7500
    Ariary::fromFloat(0.07)->toFmg(); // 0.35 (exact)
    Ariary::formatFmg(7500); // 'Fmg 7 500'
    Ariary::formatFmg(7500.5); // 'Fmg 7 500,5'
    ```
  </TabItem>
</Tabs>

## Hadisoana

| Fampidirana | Kaody hadisoana |
| --- | --- |
| Tsy isa voafetra, safidy diso, na tarehintsoratra mitovy ho an’ny arivo sy ny faingo | `INVALID_TYPE` |
| Soratra misy marika, teboka ho faingo (raha tsy misy safidy) na vola hafa | `INVALID_FORMAT` |
| Ambanin’ny 0, na mihoatra ny isa marina lehibe indrindra amin’ilay fiteny | `OUT_OF_RANGE` |
